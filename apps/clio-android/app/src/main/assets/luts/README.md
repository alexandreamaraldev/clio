# Filter LUTs

All `.cube` files in this folder are generated by `apps/clio-android/tools/gen_luts.py` from colour
math written for Clio. No third-party LUT data is used. They are released under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) (public domain), attribution: Clio contributors.

Regenerate them with `python3 tools/gen_luts.py`. Ids must match `FILTERS` in `crates/ffi-mobile/src/look.rs`.
